# 平台接口

本文定义 Lyren 的平台能力、账号连接方式和共享请求约定。界面根据适配器提供的能力显示操作入口。

| 歌单维护 | 创建、重命名、删除、增删歌曲及顺序调整 | 创建、重命名、删除、增删歌曲及顺序调整 |

## 汽水账号连接

公开搜索、歌单、榜单、歌手、专辑、评论及公开媒体可匿名读取。账号资料库、写操作和应用取流通过账号面板导入会话：

```json
{
  "signer_url": "http://127.0.0.1:8000",
  "signer_token": "<token>",
  "cookie": "sessionid=<session>; sid_tt=<session>"
}
```

配置值均为字符串。`signer_token` 可省略；`cookie_jar` 可代替 `cookie`，其内容为保留域名、路径、Secure 和有效期的 Netscape Cookie jar。

`signer_url` 指向用户配置的签名服务。Lyren 使用以下服务契约：

| 请求 | 输入 | 响应 |
|---|---|---|
| `GET /config` | 无请求体 | `ok:true`；`identity` 中的 `device_id`、`iid`、`fp` |
| `POST /sign` | `url`、`method`、`body`、`headers`、`ts_ms` | `ok:true`；`headers` 中的 `x-helios` 和 `x-medusa` |

签名请求的 `body` 为将要发送的原始正文字符串，`headers` 为请求头对象，`ts_ms` 为毫秒时间戳。响应可提供 `ms_token` 或 `msToken`，以及 `a_bogus`，用于补充业务 URL 的查询参数。服务失败响应使用 `ok:false` 和 `error`。

配置中的 `device_id`、`iid` 和 `fp` 可补充服务未提供的身份字段，并须与签名上下文一致。服务 Token 通过 `Authorization: Bearer <token>` 发送给签名服务。业务请求使用对应 Cookie 和签名，不重新序列化已经签名的正文。

导入成功后替换平台会话并加密保存；关闭连接窗口取消待完成的导入。匿名查询使用本机生成的设备标识。需要额外账号验证时，平台会返回相应的验证状态。

## 媒体与响应约定

- 汽水公开媒体由 SEO 接口读取；`video_model.video_meta` 描述候选流的音质和码率。歌词支持绝对时间及 KRC 相对时间两种结构。
- 非分段 AAC MP4 的 CENC 解码支持 8/16 字节 IV 及明文/密文子段，在解码线程逐采样处理，保留 Range 下载和进度跳转。
- 酷狗歌词支持 KRC 逐字时间、翻译与 LRC；音频格式支持范围由解码器及平台授权结果共同决定。
- 波点搜索分页结合页容量和返回的总数信息；收藏及关注接口的 `data:{}` 表示空页。非空页使用接口定义的总数和列表字段。

酷狗通过 `/risk/v3/r_register_dev` 注册设备，将返回的 `dfid` 与会话一同保存。二维码、账号歌单和取流使用同一设备身份；`count:0, info:null` 表示空歌单。平台验证状态保留其业务码和错误说明。

## 歌单写入与批量编辑

- 网易云、QQ、汽水、波点的歌曲列表支持多选、Ctrl 点选、Shift 连选、勾选全部及 Ctrl+A；全选范围是当前已经加载的歌曲。可批量添加到已有或新建歌单，自建歌单可批量移除。搜索分页继续保留选择，切换页面、平台或搜索类型时清空；Esc 或「完成选择」退出多选。
- `Provider` 的编辑接口接收歌曲列表，共享界面每批最多提交 100 首。QQ 保留各首歌曲的数值 ID 和歌曲类型，网易云和汽水保留字符串 ID，波点按协议发送数值 ID。
- 歌单写回和读取确认均检查账号是否仍为发起请求的账号；退出或更换账号后，旧结果不再修改目录、曲目、待写状态或触发后续加歌。网易云、波点的请求层也拒绝旧会话的迟到响应，阻止读取旧资料后用新账号继续写入。
- 同一歌单保存期间暂停新的编辑和排序。改名、删除使用读回目录确认结果；增删歌曲读回完整曲目和目录，并显示实际完成数量。发生部分失败时保留未完成的选择，响应丢失也不自动重放写请求。
- 创建响应缺少新歌单 ID 时刷新目录并提示结果未确认；不根据同名歌单推断 ID 或继续加歌。成功返回的 ID 可用于后续批量添加。
- 读回失败时保留已有曲目并提供重试；未知的完整顺序需要刷新确认后才能继续排序。歌单刷新同时更新目录资料，标题与侧栏使用服务端返回的名称。

## 听众主页与动态

`Provider` 通过 `profiles`、`people`、`follow_users`、`posts`、`post_write`、`ranking`、`profile_playlists` 声明能力，主页只显示平台支持的板块。没有 `profiles` 的平台仍可打开当前账号的主页，名称和头像取自账号资料。

- 网易云资料读取 `/api/v1/user/detail/{uid}`，用户搜索使用 cloudsearch 类型 `1002`。关注列表 `/api/user/getfollows/{uid}` 用 `offset` 翻页，公开的列表不需要登录，对方隐藏时返回 `code:400` 和 `用户隐私无权限查看`；粉丝列表 `/api/user/getfolloweds/{uid}` 需要登录，另外返回 `size` 作为总数。列表读取失败且未登录时，界面提示登录。
- 听歌排行 `/api/v1/play/record` 的 `type` 为 `1` 表示最近一周，`0` 表示所有时间；`code:-2` 表示对方未公开。最近一周为空时显示所有时间。
- 个人动态 `/api/event/get/{uid}` 返回 `events`，关注动态 `/api/v1/event/get` 返回 `event`，两者都用 `lasttime` 继续翻页。动态正文是字符串形式的 JSON；转发的原动态位于正文的 `event` 字段，其 `json` 同样是字符串。评论线程为 `A_EV_2_{动态 ID}_{作者 ID}`。
- 关注、点赞、发表、转发和删除要求业务码为 `200`，其余返回码按失败处理并显示服务端说明。点赞和关注先更新界面，失败后恢复；写请求不自动重放。
- QQ 音乐的关系列表使用 `music.concern.RelationList`，他人主页附带 `HostUin`（`EncUin`）。主页头部接口不可用，他人的名称和头像来自打开主页时的来源卡片。

## 共享请求约定

平台适配器实现 `Provider` 契约，并复用 HTTP 请求、图片缓存、播放缓冲和解码器。分页保留服务端继续位置，播放使用歌曲所属平台的账号和媒体资源。

账号写请求不自动重放。歌单变更后读取受影响的目录和曲目，使用服务端结果更新界面。退出或切换账号后，前一会话的响应不再修改当前状态。
