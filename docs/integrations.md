# 平台接口

本文定义 Lyren 的平台能力、账号连接方式和共享请求约定。界面根据适配器提供的能力显示操作入口。

## 网易云与 QQ 音乐

| 能力 | 网易云音乐 | QQ 音乐 |
|---|---|---|
| 搜索与资料 | 歌曲、专辑、歌手、歌单及分页 | 歌曲、专辑、歌手、歌单及分页 |
| 发现 | 推荐、榜单、歌单分类、新歌新碟、私人 FM | 推荐、榜单、歌单分类、新歌新碟、猜你喜欢、雷达推荐 |
| 资料库 | 喜欢、收藏歌单与专辑、关注歌手、云盘 | 喜欢、收藏歌单与专辑、关注歌手 |
| 歌单维护 | 创建、重命名、删除、增删歌曲及顺序调整 | 创建、重命名、删除、增删歌曲及顺序调整 |
| 评论 | 热门、最新、回复、点赞、发表及删除 | 热门、最新、回复、点赞、发表及删除 |
| 账号 | 二维码登录、凭据加密保存 | 二维码登录、会话续期、凭据加密保存 |
| 最近播放 | 本机及账号记录 | 本机记录 |

搜索、资料库和分页状态按平台独立保存。搜索使用接口返回的下一页位置；列表显示条数不用于推导服务端游标。QQ 音乐的请求参数和响应结构见 [QQ 音乐接口规范](qqmusic-api.md)。

图片 URL 中的 `{size}` 在下载时按显示尺寸展开。路径中的空格编码为 `%20`，保留已有转义和查询参数。

## 汽水账号连接

公开搜索、歌单、榜单、歌手、专辑、评论及公开媒体可匿名读取。账号资料库、写操作和应用取流通过账号面板导入会话：

```json
{
  "signer_url": "http://127.0.0.1:8000",
  "signer_token": "<token>",
  "cookie": "sessionid=<session>; sid_tt=<session>"
}
```

配置值均为字符串。`signer_token` 可省略；`cookie_jar` 可代替 `cookie`，其内容为保留域名、路径、Secure 和有效期的 Netscape Cookie jar。

`signer_url` 指向用户配置的签名服务。Lyren 使用以下服务契约：

| 请求 | 输入 | 响应 |
|---|---|---|
| `GET /config` | 无请求体 | `ok:true`；`identity` 中的 `device_id`、`iid`、`fp` |
| `POST /sign` | `url`、`method`、`body`、`headers`、`ts_ms` | `ok:true`；`headers` 中的 `x-helios` 和 `x-medusa` |

签名请求的 `body` 为将要发送的原始正文字符串，`headers` 为请求头对象，`ts_ms` 为毫秒时间戳。响应可提供 `ms_token` 或 `msToken`，以及 `a_bogus`，用于补充业务 URL 的查询参数。服务失败响应使用 `ok:false` 和 `error`。

配置中的 `device_id`、`iid` 和 `fp` 可补充服务未提供的身份字段，并须与签名上下文一致。服务 Token 通过 `Authorization: Bearer <token>` 发送给签名服务。业务请求使用对应 Cookie 和签名，不重新序列化已经签名的正文。

导入成功后替换平台会话并加密保存；关闭连接窗口取消待完成的导入。匿名查询使用本机生成的设备标识。需要额外账号验证时，平台会返回相应的验证状态。

## 媒体与响应约定

- 汽水公开媒体由 SEO 接口读取；`video_model.video_meta` 描述候选流的音质和码率。歌词支持绝对时间及 KRC 相对时间两种结构。
- 非分段 AAC MP4 的 CENC 解码支持 8/16 字节 IV 及明文/密文子段，在解码线程逐采样处理，保留 Range 下载和进度跳转。
- 酷狗歌词支持 KRC 逐字时间、翻译与 LRC；音频格式支持范围由解码器及平台授权结果共同决定。
- 波点搜索分页结合页容量和返回的总数信息；收藏及关注接口的 `data:{}` 表示空页。非空页使用接口定义的总数和列表字段。

酷狗通过 `/risk/v3/r_register_dev` 注册设备，将返回的 `dfid` 与会话一同保存。二维码、账号歌单和取流使用同一设备身份；`count:0, info:null` 表示空歌单。平台验证状态保留其业务码和错误说明。

## 共享请求约定

平台适配器实现 `Provider` 契约，并复用 HTTP 请求、图片缓存、播放缓冲和解码器。分页保留服务端继续位置，播放使用歌曲所属平台的账号和媒体资源。

账号写请求不自动重放。歌单变更后读取受影响的目录和曲目，使用服务端结果更新界面。退出或切换账号后，前一会话的响应不再修改当前状态。
