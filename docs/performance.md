# 资源与调度

## 缓存

缓存拥有字符串键，查询借用 `string_view`。文字缓存区分文本与字体特性；图标区分名称与尺寸；图片区分资源地址、尺寸和模糊版本；评论状态区分评论 ID 与平台。公共键类型见 [string_map.hpp](../src/core/string_map.hpp)。

透明查找在命中时不构造拥有字符串的临时键。组合键在未命中后构造并插入，翻译目录使用透明哈希查找。图片下载地址在请求时生成。

## 图片加载

图片工作池包含 2 个线程，空闲时休眠。下载结果交给工作池解码、缩图、取色及模糊，纹理上传和应用状态更新回到主事件循环。实现见 [images.cpp](../src/app/images.cpp)。

并发任务上限为 6，后台任务最多占 2 个，可见请求优先。同一资源的预取与显示请求合并；切换页面后可复用已取得的结果。

缓存预算为 24 MB、512 条记录。排队时预留像素容量，完成后按实际用量计费；后台预取使用剩余预算。缓存可以复用较大尺寸的图片，并在清晰图到达前显示缩略图。

发现页预加载和缓存管理由应用层调度。关闭图片缓存时取消下载并等待工作池结束。

## 线程与内存布局

主线程管理 Wayland、界面、Vulkan 和应用状态。网络、图片及解码线程通过事件循环交付结果；`Loop::post` 在待执行队列从空变为非空时发送唤醒。

音频生产者的写指针与 flush 状态、消费者的读指针与播放位置分处 64 字节缓存行。PipeWire SPA 参数按 8 字节对齐；GPU 图元按 16 字节对齐，布局与着色器一致。

音频缓冲使用匿名文件及环形缓冲，解码和文件读取在实时输出回调之外完成。

## 构建与测量

Release / RelWithDebInfo 默认启用 LTO。`LYREN_NATIVE=ON` 按本机 CPU 生成代码，`LYREN_LTO=OFF` 关闭链接时优化。

内存测量应固定构建参数、窗口尺寸、平台、页面数据和缓存状态，记录 `/proc/<pid>/status` 与 `/proc/<pid>/smaps_rollup`。空闲 CPU 测量在动画和下载结束后读取进程计数；图形验证层的额外开销单独记录。

功能验证通过 CTest 执行。图形测试使用私有 Wayland / Vulkan 会话和独立的数据目录；测试参数见[构建说明](../README.md)。
